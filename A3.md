## 🚀 A3: CI and CD Pipeline with GitHub Actions

This repository includes the implementation of basic CI and CD pipelines using GitHub Actions. The workflows are divided into two separate files.

### 🛠️ Continuous Integration (CI)
Defined in `.github/workflows/ci.yml`.
* **Triggers:** Runs automatically on `push` or `pull_request` events to the `develop` branch.
* **Tasks:** It performs basic validation tasks. Specifically, it sets up the necessary environments (Python 3.11.8 and Node.js 24.12.0), installs project dependencies (`npm install`), and runs unit tests (`npm test`) to ensure code integrity before integration.

### 📦 Continuous Delivery (CD)
Defined in a separate file (`cd.yml`) to specifically handle the delivery of the project.
* **Triggers:** Runs on a `push` to the `develop` branch or manually via `workflow_dispatch`.
* **Delivery Approach:** It prepares the application for production by setting up Node.js, running a clean installation of dependencies (`npm ci`), and executing the production build command (`npm run build-prod`).
* **Artifact Generation:** Instead of deploying directly to a server, this workflow uses a Continuous Delivery approach. It packages the resulting `dist/` folder and uploads it as a downloadable GitHub Artifact named `ruxailab-production-build`, leaving the project fully ready for manual deployment to any hosting service.
